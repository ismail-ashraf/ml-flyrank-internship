# Portfolio Identity Kit

---

## 1. Logo / Brand Mark
```
  [ MA ]
```
> **Identity:** Simple Monogram logo using **Inter** (Bold / Semi-Bold).

---

## 2. Typography
* **Heading Font:** `Inter` (Bold, 700) — *Clean, crisp, modern headers.*
* **Body Font:** `Inter` (Regular, 400) — *Highly legible for long-form case studies.*

---

## 3. Color Palette
| Visual | Role | Hex Code | Usage |
| :---: | :--- | :--- | :--- |
| ⬛ | **Main Text** | `#111827` | Headings, body text, primary elements |
| ⬜ | **Background** | `#FAFAFA` | Clean, subtle near-white page background |
| 🟦 | **Accent** | `#2563EB` | Interactive elements, links, focus states |
| 🌫️ | **Border / Muted** | `#E5E7EB` | Dividers, card borders, secondary details |

---

## 4. Two-Line Style Note
> **Fonts & Palette:** Using `Inter` with near-black `#111827` text on `#FAFAFA` background, accented by a calm `#2563EB` blue and crisp `#E5E7EB` subtle borders.  
> **Mood & Atmosphere:** Minimalist, deliberate, and engineered for readability, ensuring the technical depth of the work remains the focal point.
