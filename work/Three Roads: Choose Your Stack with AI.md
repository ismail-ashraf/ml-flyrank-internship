Selected Stack Rationale: Astro + Tailwind CSS (Hosted on Vercel)

Constraints Considered:

Cost: Free only.

Skill Level: Strong with Python/ML, prefer straightforward frontend setups without complex reactive state logic.

Work Display: Need clean layouts to feature ML system architectures (RAG, PyTorch pipelines), GitHub links, and embedded markdown descriptions.

Backend: Not yet. A static site is more than enough for now.

Options Evaluated:

Vanilla HTML/CSS/JS (GitHub Pages): Simplest option, but adding new case studies requires manually editing HTML structures every time.

Astro + Tailwind (Vercel): Chosen. Offers maximum performance, zero JavaScript overhead by default, and allows me to manage projects via simple Markdown files without complex setups.

Next.js (Vercel): Overkill for my current scope. High maintenance burden and unnecessary routing complexity for a static portfolio.

Why this choice?
Can I maintain this? Yes, Astro is extremely low-maintenance, and Vercel takes care of automatic deployments from GitHub. Does it show my work well? Absolutely—it allows me to present technical deep-dives and deep learning architecture breakdowns clearly using Markdown.
